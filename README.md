# Os principais problemas:

os principais problemas foi com deixar a imagem de fundo mais escura, sinceramente é extremamente dificil, e muito mais facil de fazer usando um editor de imagem, tirando isso foi bem tranquilo.
Outra coisa foi na imprementação do java, é algo super básico que apenas gera um numero aleatorio entre 1 a 200, a ideia original era fazer com que gerasse um número aleatorio quando entrasse na página e depois de clicar no botão adicionar +!, mas isso não deu muito certo então apenas virou um gerador de números aleatorios.
